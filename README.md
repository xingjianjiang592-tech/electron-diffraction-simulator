# 🔬 电子衍射模拟器 · Electron Diffraction Simulator

![HTML5 Canvas 2D](https://img.shields.io/badge/HTML5-Canvas%202D-orange)
![无外部依赖](https://img.shields.io/badge/dependencies-none-brightgreen)
![License: MIT](https://img.shields.io/badge/license-MIT-blue)

一个基于纯 HTML + Canvas 2D 的交互式电子衍射模拟器。**无外部依赖，单文件运行**，打开浏览器即可使用。

模拟核心基于 **厄瓦尔德球与倒易点阵相交决定衍射斑** 的物理原理，覆盖单晶、多晶、非晶、准晶以及多种晶体缺陷的电子衍射花样。

## ✨ 功能特性

### 衍射模式

- **单晶衍射**：斑点强度 ∝ |F|² · exp(-(s/σ)²)
- **多晶（德拜-谢乐环）**：环半径 R = L·tan(2θ)
- **非晶（短程序）**：液体/硬球模型产生弥散晕环
- **准晶**：十重 / 八重 / 十二重 / 五重对称

### 晶体结构（17 种预设）

P、I、F、C、A、B、金刚石、NaCl、CsCl、ZnS、HCP、纤锌矿 ZnO、钙钛矿 SrTiO₃、金红石 TiO₂、L1₂ Cu₃Au、L1₀ CuAu、自定义基元

### 特殊效应

| 功能 | 说明 |
|---|---|
| **二次衍射** | 强反射 g₁+g₂ 产生新斑，可复活消光位置 |
| **高阶劳埃斑 (HOLZ)** | \|g_z\| 超阈值标记为暖橙色 |
| **镜像孪晶** | 沿任意 hkl 面镜面反射 |
| **三重孪晶** | 绕任意 uvw 轴生成 120°/240° 变体 |
| **菊池线** | 过量线（亮青）/ 缺陷线（暗灰） |
| **晶体缺陷** | TDS / 点缺陷 / 位错 / 层错 / 小角晶界 / 纳米晶 / 析出相 |

### 交互特性

- ✅ **带轴快速取向**：输入 `[uvw]` 自动计算零层衍射，支持 `001`、`1,1,1`、`1-11` 三种写法
- ✅ **3D 厄瓦尔德球视图**：鼠标拖动旋转
- ✅ **数值输入框**：可直接输入，Enter/失焦生效，↑/↓ 微调
- ✅ **导出 PNG**：一键保存当前衍射花样
- ✅ **参数持久化**：自动保存到 localStorage，刷新后恢复
- ✅ **模式联动**：切换样品类型时自动适配视野、置灰不生效的控件

## 🚀 使用方式

### 方式一：直接打开（最简单）

1. 下载 `elec.html`
2. 双击用浏览器打开

### 方式二：在线访问

访问你的 GitHub Pages 部署地址（如 `https://username.github.io/electron-diffraction/`）

### 快速上手

1. 在顶部**带轴**输入框输入 `001`，按 Enter
2. 观察右侧衍射花样应为正方形零层斑点
3. 把带轴换成 `111`，观察花样变为六角对称
4. 尝试从下拉菜单选择不同晶体（如 F 面心立方、NaCl、准晶 Q10）
5. 开启**二次衍射**，观察原本消光位置出现淡紫色斑

## 📐 物理模型

### 波长（相对论修正）

```
λ = 1.22639 / sqrt(U·(1 + 0.97845×10⁻⁶·U))   // U 单位 V，λ 单位 nm
```

### 倒易基矢

由实空间晶格 a, b, c 和角度 α, β, γ 计算：

```
a* = (b × c) / V
b* = (c × a) / V
c* = (a × b) / V
```

### 厄瓦尔德球衍射条件

电子束沿 +z，k₀ = (0, 0, 1/λ)：

```
|k₀ + g| = |k₀|   ⇒   g_z = -λ|g|²/2
偏离矢量 s = λ|g|²/2 + g_z
强度 I ∝ |F(hkl)|² · exp(-(s/σ)²)
```

### 探测器坐标

```
kz = 1/λ + g_z
X = L · g_x / kz
Y = L · g_y / kz
```

### 结构因子

```
F(hkl) = |Σ wᵢ·exp(2πi·(hxᵢ + kyᵢ + lzᵢ))|
Fn = F / Σwᵢ
```

### 带轴取向

电子束沿 [uvw] 入射 ⇔ 倒易面 (uvw)* 转到水平：

```
n = u·a + v·b + w·c    （实空间向量）
R_zone · n̂ = ẑ        （最短旋转，Rodrigues 公式）
```

### 二次衍射

源斑 s₁, s₂ 强度分别为 I₁, I₂：

```
g_double = g₁ + g₂
I_double ∝ I₁ · I₂ · amt
```

### 孪晶

**镜像孪晶**（对孪晶面倒易矢量 g）：

```
M = I - 2·g·gᵀ / |g|²
```

**三重孪晶**（绕轴 uvw，罗德里格斯公式）：

```
R = I·cosθ + sinθ·[u]× + (1-cosθ)·u·uᵀ
```

## 🗂️ 项目结构

单文件 HTML，无外部依赖：

```
elec.html          ← 主程序
README.md          ← 本文档
screenshot.png     ← 预览图（可选）
```

主要模块（按代码内顺序）：

| 模块 | 作用 |
|---|---|
| `PRESETS` | 所有晶体预设（基元 + 晶格常数） |
| `groups` | UI 参数分组定义 |
| `state` | 当前参数值（自动持久化） |
| `wavelength` | 电压 → 波长 |
| `recipLattice` | 实空间 → 倒易基矢 |
| `computeZoneAxisMatrix` | 带轴 [uvw] → 取向矩阵 |
| `computeReflections` | 单晶/准晶所有反射（含孪晶） |
| `computeRings` | 多晶德拜环 |
| `computeAmorphousRings` | 非晶弥散晕环 |
| `addDoubleDiffraction` | 二次衍射 |
| `applyDefects` | 晶体缺陷效果 |
| `drawSinglePattern` | 绘制单晶花样 |
| `drawPolyPattern` | 绘制多晶环 |
| `drawAmorphousPattern` | 绘制非晶晕环 |
| `draw3D` | 绘制三维厄瓦尔德球 |
| `render` | 总调度 |

## ⚙️ 参数说明

### 电子束

- `voltage` 加速电压：10–1000 kV，默认 200
- `camLen` 相机长度 L：100–3000 mm，默认 800

### 晶格常数

- `a, b, c`：0.15–1.20 nm
- `alpha, beta, gamma`：30–150°

### 衍射与显示

- `maxIndex` 最高指数：1–6
- `sigma` 斑点展宽：0.005–0.30 nm⁻¹
- `viewR` 视野半径：3–60 mm
- `curvature` 球面曲率放大：0.01–1

### 二次衍射

- `doubleDiffraction`：on/off
- `doubleAmt` 强度系数：0–1
- `doubleMax` 源斑上限：3–24
- `doubleSource` 源斑类型：`matrix`（仅原晶）/ `all`（原晶+孪晶）

## 📌 已知限制

1. **多晶/非晶模式**：孪晶、HOLZ、二次衍射、缺陷不适用（UI 已置灰）
2. **准晶模式**：孪晶、二次衍射、缺陷不适用
3. **二次衍射** 为运动学近似，非 Bloch 波动力学求解
4. **准晶层数** 固定 ±2 层，未参数化
5. **Q5 预设** 的 `quasi.n` 实际为 10（五重准晶衍射呈十重对称）
